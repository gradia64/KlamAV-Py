# Security Policy

## Supported Versions

Currently, only the latest released version of KlamAV-Py receives
security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | :white_check_mark: |
| < 0.1    | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in KlamAV-Py, please report it
privately rather than opening a public GitHub issue.

You can report vulnerabilities using GitHub's private vulnerability
reporting feature available in this repository.

Please provide as much information as possible, including:

- the KlamAV-Py version affected;
- a description of the vulnerability;
- steps to reproduce the issue;
- any relevant logs or screenshots;
- the potential impact of the vulnerability.

We will review the report and provide an update as soon as reasonably
possible.

Please do not publicly disclose the vulnerability until it has been
investigated and, where appropriate, a fix has been released.
